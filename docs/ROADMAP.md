# Roadmap

Eine Zeile pro Etappe. Abhaken, wenn erledigt.

## Muss (fertige Browser-Simulation)

- [x] **0 Setup:** Vite, React, TypeScript, Tailwind, pnpm, GitHub-Repo
- [x] **1 Logik:** Raster erzeugen, Patient 0 setzen, einen Schritt berechnen (mit Unit-Tests)
- [ ] **2 Anzeige:** Raster als CSS-Grid darstellen
- [ ] **3 Steuerung:** Play, Pause, Einzelschritt, Tempo, Dichte, Grösse, Patient 0 per Klick
- [ ] **4 Optik:** "Nachtkarte" mit leuchtenden Menschen und pulsierenden Zombies, Zähler
- [ ] **5 Qualität:** End-to-End-Test und GitHub Actions

## Soll (Fullstack)

- [ ] **6 Backend:** kleine REST-API mit Node.js
- [ ] **7 Datenbank:** Experimente in PostgreSQL speichern und laden
- [ ] **8 Auswertung:** viele Durchläufe pro Dichte, Diagramm zur 59 %-Schwelle

## Kann (Bonus)

- [ ] **9 Extras:** Canvas, 8er-Nachbarschaft, Deployment, eine Etappe ganz ohne KI
